# 节点分布世界地图截图 / Node distribution map screenshots

**中文**

本目录由 `web/scripts/shots-world-map.mjs` 生成，覆盖「资源状态」视图里的
「节点分布」世界地图卡。本轮把「圆点颜色 = 最差状态」改成「圆点 = 有节点，
状态 = 外环」：离线国家一度整图红点，容易被读成「红点 = 这里有节点」，
和离线语义混淆；现在圆点始终是主题主色，状态只由外环表达。

- **投影与裁切**：仍是等距圆柱投影，viewBox 只保留 lat `+78°..-56°`
  （`0 33.3 1000 372.2`）；路径坐标仍用完整的 1000×500 坐标系。格陵兰南缘、
  新西兰、南美南端都保留，南极与北极圈上方的空白去掉。
- **海洋与陆地**：海洋就是卡片底色；无节点陆地用 `fill-muted-foreground/20`。
  实测这层对卡片底色的对比度是暗色 **1.35:1** / 亮色 **1.31:1**；
  规范里写的 `fill-muted/40` 只有 **1.04:1**，在亮色白卡上几乎完全看不出来，
  所以按「能看出轮廓」的目标取深一档，仍然只走主题 token。
- **有节点国家**：primary 四档 `20 / 35 / 55 / 80%`，加 `stroke-primary/40`
  0.5px 描边。离线 / 降级不再给整国红 / 黄描边，避免看起来「整国出事」。
- **圆点 = 有节点**：`build-world-map.mjs` 为每个国家输出最大陆块的面积质心
  `c: [x, y]`；每个有节点的国家在质心画圆点，半径按档位 **3 / 4 / 5 / 6px**
  （屏幕像素，390 下用 ResizeObserver 换算回 viewBox 单位），始终用主题主色
  `fill-primary`，2px 卡片底色描边形成「挖空」感。≥2 台的国家在圆点右侧显示
  12px `N` 标签，标签也改为主色，390 下相邻标签自动垂直错开。
- **状态 = 外环**：最差状态 `offline` 加 `stroke-destructive` 外环，
  `abnormal` 加 `stroke-warning` 外环；外环半径统一 **+2.5px**、**2px 宽**；
  `online` 没有外环。focus ring 在有外环时再向外让 3px，键盘反馈不变。
- **图例拆两段**：左侧「节点数」+ 四档 10×10 色块；右侧 12px 圆点 / 外环示意
  「在线（无环）· 离线 · 异常」。两段之间用 1px 分隔线，390 下换行但不横向溢出。
- **tooltip**：国家名、`N 台 · 在线 M`、状态、前 3 个节点名；状态文字与外环同义。
- **交互**：hover / 键盘聚焦时 fill 提亮一档、加 1.5px primary 描边；
  键盘聚焦另有 focus ring。点击行为不变（`/servers?country=XX`）。
- **数据**：截图 fixture 固定 22 台（混合场景 19 在线 / 1 离线 / 2 异常）；
  真实预览已重新造数为 **10 在线 / 5 离线**，本轮未改数据。

**English**

Generated by `web/scripts/shots-world-map.mjs` for the "Node distribution" world
map card in the resource-status view. This pass changes "dot colour = worst
status" to "dot = nodes exist, status = outer ring": with every node offline the
whole map used to be red dots, which read as "a red dot means a node lives here"
and got confused with the offline state. The dot is now always the theme primary
colour and only the outer ring carries status:

- **Projection / crop**: still equirectangular; the viewBox keeps only lat
  `+78°..-56°` (`0 33.3 1000 372.2`) while path coordinates stay in the full
  1000×500 space. Southern Greenland, New Zealand and the southern tip of South
  America remain; Antarctica and the empty Arctic band are gone.
- **Ocean / land**: the ocean is the card background; countries without nodes
  use `fill-muted-foreground/20`. Measured against the card this is **1.35:1** in
  dark and **1.31:1** in light; the literal `fill-muted/40` is only **1.04:1**
  and disappears on the light card, so one step stronger is used while keeping
  the theme tokens.
- **Countries with nodes**: four primary fills at `20 / 35 / 55 / 80%` plus a
  `stroke-primary/40` 0.5px outline. Offline / degraded no longer paint the
  whole country red / yellow, which used to read as "the whole country is down".
- **Dot = nodes exist**: `build-world-map.mjs` emits the area centroid of each
  country's largest landmass as `c: [x, y]`. Each country with nodes gets a dot
  at that centroid with a **3 / 4 / 5 / 6px** radius (screen pixels, converted
  back to viewBox units through a ResizeObserver at 390), always filled with the
  theme primary (`fill-primary`) and a 2px card-coloured stroke for the cut-out
  look. Countries with ≥2 nodes show a 12px `N` label to the right, also in the
  primary colour; nearby labels are nudged vertically at 390.
- **Status = outer ring**: the worst status `offline` adds a
  `stroke-destructive` ring, `abnormal` adds a `stroke-warning` ring; every ring
  is **+2.5px** in radius and **2px** wide, while `online` has no ring. The focus
  ring moves 3px further out when a status ring is present, so keyboard feedback
  stays the same.
- **Two-part legend**: the left part is "Nodes" with four 10×10 tier swatches;
  the right part uses 12px dot / ring glyphs for "Online (no ring) · Offline ·
  Abnormal". A 1px divider separates the parts; at 390 it wraps without
  overflowing.
- **Tooltip**: localized country, `N nodes · M online`, status, and the first
  three node names; the status text matches the ring.
- **Interaction**: hover / keyboard focus lightens the fill one step and adds a
  1.5px primary outline; keyboard focus also gets a focus ring. Clicking still
  navigates to `/servers?country=XX`.
- **Data**: the screenshot fixture is a fixed 22 nodes (mixed scenario: 19
  online / 1 offline / 2 abnormal); the real preview has been reseeded to
  **10 online / 5 offline**, and no data was changed in this pass.
