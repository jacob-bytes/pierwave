# 节点分布世界地图截图 / Node distribution map screenshots

**中文**

本目录由 `web/scripts/shots-world-map.mjs` 生成，覆盖「资源状态」视图里的
「节点分布」世界地图卡。本轮改版把地图从 2:1 的居中窄图改成横向拉满的裁切图，
并给每个有节点的国家加质心圆点，解决香港 / 新加坡 / 澳门这类小地区看不见的问题：

- **投影与裁切**：仍是等距圆柱投影，viewBox 只保留 lat `+78°..-56°`
  （`0 33.3 1000 372.2`）；路径坐标仍用完整的 1000×500 坐标系。格陵兰南缘、
  新西兰、南美南端都保留，南极与北极圈上方的空白去掉。
- **海洋与陆地**：海洋就是卡片底色；无节点陆地用 `fill-muted-foreground/20`。
  实测这层对卡片底色的对比度是暗色 **1.35:1** / 亮色 **1.31:1**；
  规范里写的 `fill-muted/40` 只有 **1.04:1**，在亮色白卡上几乎完全看不出来，
  所以按「能看出轮廓」的目标取深一档，仍然只走主题 token。
- **有节点国家**：primary 四档 `20 / 35 / 55 / 80%`，加 `stroke-primary/40`
  0.5px 描边。离线 / 降级不再给整国红 / 黄描边，避免看起来「整国出事」。
- **质心圆点**：`build-world-map.mjs` 为每个国家输出最大陆块的面积质心
  `c: [x, y]`；每个有节点的国家在质心画圆点，半径按档位 **3 / 4 / 5 / 6px**
  （屏幕像素，390 下用 ResizeObserver 换算回 viewBox 单位），2px 卡片底色描边。
  离线圆点 `destructive`，降级圆点 `warning`；≥2 台的国家在圆点右侧显示 12px
  `N` 标签，390 下相邻标签自动垂直错开。
- **图例**：卡片底部右侧一行，12px 字号、10×10 色块，四档 + 离线 / 异常；
  390 下换行但不横向溢出。
- **交互**：hover / 键盘聚焦时 fill 提亮一档、加 1.5px primary 描边；
  键盘聚焦另有 focus ring。点击行为不变（`/servers?country=XX`）。

- `world-map-hover-{dark,light}-{1440,390}.png`：hover 提亮 + 1.5px 描边 + tooltip；
- `world-map-focus-1440.png`：键盘聚焦的 focus ring；
- `world-map-tooltip-{1440,390}.png`：悬停 / 聚焦 tooltip（本地化国家名、台数、在线数、前 3 个节点名；390 不越界）；
- `world-map-small-regions-{1440,390}.png`：只有 HK / SG 两个小地区时，质心圆点与 `N` 标签仍可见；
- `server-country-filter-1440.png`：点击 / 键盘 Enter 跳转 `/servers?country=DE` 后的列表与「地区 DE」chip；
- `server-country-filter-390.png`：390 下服务器页的地区筛选 chip 与卡片列表；
- `server-country-empty-1440.png`：`/servers?country=NZ` 的空态「该地区没有服务器」；

**English**

Generated by `web/scripts/shots-world-map.mjs` for the "Node distribution" world
map card in the resource-status view. This pass turns the 2:1 centred map into a
full-width cropped map and adds a centroid dot per country with nodes, so small
regions such as Hong Kong, Singapore and Macau stay visible:

- **Projection / crop**: still equirectangular; the viewBox keeps only lat
  `+78°..-56°` (`0 33.3 1000 372.2`) while path coordinates stay in the full
  1000×500 space. Southern Greenland, New Zealand and the southern tip of South
  America remain; Antarctica and the empty Arctic band are gone.
- **Ocean / land**: the ocean is the card background; countries without nodes
  use `fill-muted-foreground/20`. Measured against the card this is **1.35:1** in
  dark and **1.31:1** in light; the literal `fill-muted/40` is only **1.04:1**
  and disappears on the light card, so one step stronger is used while keeping
  the theme tokens.
- **Countries with nodes**: four primary fills at `20 / 35 / 55 / 80%` plus a
  `stroke-primary/40` 0.5px outline. Offline / degraded no longer paint the
  whole country red / yellow, which used to read as "the whole country is down".
- **Centroid dots**: `build-world-map.mjs` emits the area centroid of each
  country's largest landmass as `c: [x, y]`. Each country with nodes gets a dot
  at that centroid with a **3 / 4 / 5 / 6px** radius (screen pixels, converted
  back to viewBox units through a ResizeObserver at 390) and a 2px card-coloured
  stroke. Offline dots are `destructive`, degraded dots are `warning`, and
  countries with ≥2 nodes show a 12px `N` label to the right; nearby labels are
  nudged vertically at 390.
- **Legend**: one row at the bottom right of the card, 12px type with 10×10
  swatches: four tiers plus offline / abnormal. It wraps instead of overflowing
  at 390.
- **Interaction**: hover / keyboard focus lightens the fill one step and adds a
  1.5px primary outline; keyboard focus also gets a focus ring. Clicking still
  navigates to `/servers?country=XX`.

Files:

- `overview-map-dark-1440.png`: the card in place, between the KPI strip and "Server × time";
- `world-map-{dark,light}-{1440,390}.png`: the card in light/dark at desktop and 390;
- `world-map-hover-{dark,light}-{1440,390}.png`: hover lightening, 1.5px outline and tooltip;
- `world-map-focus-1440.png`: keyboard focus ring;
- `world-map-tooltip-{1440,390}.png`: hover/focus tooltip (localized country, node count, online count, first three node names; stays inside the card at 390);
- `world-map-small-regions-{1440,390}.png`: HK / SG only, proving the centroid dots and `N` label remain visible;
- `server-country-filter-1440.png`: the server list after clicking or pressing Enter on a country (`/servers?country=DE`), including the "Region DE" chip;
- `server-country-filter-390.png`: the region chip and card list at 390;
- `server-country-empty-1440.png`: `/servers?country=NZ` empty state ("No servers in this region");
- `world-map-empty-{dark,light}-{1440,390}.png`: the map stays visible with no mappable nodes and the legend says "No nodes yet";
- `compare-{dark,light}-1440.png`: before / after side by side; `before/` holds the two original pre-change shots;
- `report.json`: per-shot metrics, every runtime assertion and the contrast data.
