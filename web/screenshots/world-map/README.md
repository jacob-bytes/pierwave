# 节点分布世界地图截图 / Node distribution map screenshots

**中文**

本目录由 `web/scripts/shots-world-map.mjs` 生成，覆盖「资源状态」视图新增的
「节点分布」世界地图卡：

- `overview-map-dark-1440.png`：概览中的实际位置（KPI 条与「服务器 × 时间」之间）；
- `world-map-{dark,light}-{1440,390}.png`：亮 / 暗 × 桌面 / 390 的地图卡；
- `world-map-tooltip-{1440,390}.png`：悬停 / 聚焦 tooltip（本地化国家名、台数、在线数、前 3 个节点名；390 不越界）；
- `server-country-filter-1440.png`：点击 / 键盘 Enter 跳转 `/servers?country=DE` 后的列表与「地区 DE」chip；
- `server-country-filter-390.png`：390 下服务器页的地区筛选 chip；
- `server-country-empty-1440.png`：`/servers?country=NZ` 的空态「该地区没有服务器」；
- `world-map-empty-{dark,light}-{1440,390}.png`：没有任何可落图节点时仍显示地图，图例注明「暂无节点」；
- `report.json`：每张截图的度量与全部运行时断言。

生成 / Regenerate:

```bash
cd web
npm run build
node scripts/shots-world-map.mjs
```

断言覆盖：卡片位置、173 个 110m 国家 + 61 个 50m 补全小地区（共 234 个路径）、
8 个有节点国家的 4 档 fill、offline=destructive / abnormal=warning 描边、
图例、有节点国家可聚焦且无节点国家不可聚焦、tooltip 文案与边界、鼠标点击与
键盘 Enter 的 `/servers?country=` URL、服务器页 chip / 过滤 / 空态、390 无横向
溢出、`worldMapPaths.json` ≤150KB。

**English**

Generated by `web/scripts/shots-world-map.mjs` for the "Node distribution" world
map card in the resource-status view:

- `overview-map-dark-1440.png`: the card in place, between the KPI strip and "Server × time";
- `world-map-{dark,light}-{1440,390}.png`: the card in light/dark at desktop and 390;
- `world-map-tooltip-{1440,390}.png`: hover/focus tooltip (localized country, node count, online count, first three node names; stays inside the card at 390);
- `server-country-filter-1440.png`: the server list after clicking or pressing Enter on a country (`/servers?country=DE`), including the "Region DE" chip;
- `server-country-filter-390.png`: the region chip at 390;
- `server-country-empty-1440.png`: `/servers?country=NZ` empty state ("No servers in this region");
- `world-map-empty-{dark,light}-{1440,390}.png`: the map stays visible with no mappable nodes and the legend says "No nodes yet";
- `report.json`: per-shot metrics and every runtime assertion.

The generated JSON is built at build time and committed; no network request is
made at runtime. Shots and assertions cover card placement, 173 110m countries
plus 61 small regions added from 50m (234 paths), four fill tiers across eight
countries with nodes, offline/destructive and abnormal/warning strokes, the
legend, focus only on countries with nodes, tooltip content and bounds, mouse
click and keyboard Enter navigation, the server-page chip/filter/empty state,
no horizontal overflow at 390, and the 150KB JSON budget.
